I build the unglamorous layer that makes agents survivable: deterministic policy,
capability supervision, and tooling that refuses to lie about what it proved.

Most agent tooling assumes the model is the product. I assume the model is a
hazard with a schedule, and the interesting engineering is everything wrapped
around it — rule provenance you can audit, capability death you can detect,
demos you can verify were real, and consoles that stop needing a human to click
through them at 2 AM.

<summary><b>How I work</b></summary>

<br>

- **Prove it or drop it.** A green check that verifies nothing is worse than a red one that tells the truth.
- **Verification before publication.** Secrets scanned, personal paths stripped, licenses chosen, tests actually run — not asserted.
- **Same-user guards are not isolation.** I'll say that out loud in my own README rather than imply a boundary that isn't there.
- **Boring beats clever.** A bounded retry with a hard deadline outlives an elegant architecture with none.
